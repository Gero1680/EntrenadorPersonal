# Mi Entrenador — GitHub Pages v2

Esta versión sustituye los dibujos esquemáticos por un botón **Ver vídeo explicativo en YouTube** en cada ejercicio.

Algunos ejercicios enlazan a vídeos concretos de referencia; otros abren una búsqueda específica de YouTube para ese movimiento.

Publicación: sube todo el contenido a la raíz del repositorio y activa:
Settings → Pages → Deploy from a branch → main → /(root).
