MI ENTRENADOR — PWA

1. Descomprime la carpeta.
2. Sube su contenido a un hosting HTTPS (por ejemplo GitHub Pages, Netlify o similar).
3. Abre la URL en Chrome en Android.
4. Menú ⋮ -> "Añadir a pantalla de inicio" / "Instalar aplicación".

Los datos de entrenamiento se guardan con localStorage en el dispositivo/navegador.
Para que funcione como PWA instalable se necesita HTTPS (localhost también sirve durante desarrollo).
